# Foveance Cloud — coming soon

The open-source package is free forever (Apache-2.0). **Foveance Cloud** is the managed layer on
top, for teams that want the savings without running anything.

The pitch is simple: the proxy already measures how much it saves you, in dollars. Cloud pricing
follows the same number — if it doesn't save you money, it doesn't cost you money.
